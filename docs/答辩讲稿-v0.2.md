# v0.2 答辩讲稿

1. 选题：从三家互联网企业招聘快照抽取技能需求，演示按城市、岗位族、技能和加分条件检索。不是全行业就业分析。
2. 数据：14,974 条原始岗位，筛选后 4,904 条；390 项技能、12 分类。保留无技能岗位，统一不同导出统计。
3. 方法：词典匹配、别名归一、局部修饰规则，保存字段与字符偏移。共享技能与具体岗位要求分开建模。
4. 评测：同一 100 句 AI 标注参考集，词典 exact F1 .308，BERT .172；不是人工金标准。长尾覆盖和边界判断是主要短板。
5. 演示：打开 /evidence，杭州、算法、Python,PyTorch，查询 54 项；加分技能 LLM，查询 3 项。展示原句、链接和偏移。
6. 解释：未说明不等于必备。至少一门的选择条件仍可能被逐项误标；现阶段应以原文为准。
7. 发布：代码、图谱与评测材料准备发布 GitHub JobSkill-KG；本轮不发布 OpenKG。现场按实际仓库访问结果说明发布状态，不声称已上线 API。
8. 贡献：完整工程链路、可追溯查询和明确的质量边界。下一步是独立真人复核与更丰富的抽取方法，而不是靠测试题补词典后重新报高分。
