# 答辩问答准备（12 问）

> 每个答案都能落到具体数字或文件，避免"我们觉得"式回答。

## Q1 为什么选招聘？娱乐/动漫不是更好做吗？

招聘是唯一同时满足四条的空白区：① OpenKG 410 个数据集里「招聘」「岗位」命中为 0，「技能」只在 2 个娱乐图谱简介里作为普通词出现，没有岗位—技能类数据集；② 数据公开可得
（企业官方招聘站）；③ 技能必须抽取才能得到，不做抽取就没有图谱；④ 检索/差距分析这类应用天然成立。
娱乐题材在课程历史作业里已经饱和（`zju-kg-course` 50 个里大半是动漫/影视人物关系）。

## Q2 为什么只做 IT/算法岗？

垂直切片。全行业会有大量非技术岗位（销售、运营、设计），技能体系完全不同，词表和 schema 都要分裂。
只做 IT 后，技能可以对齐 ESCO 的 LSKT 四维，schema 扩展也只需要一套。

## Q3 数据量为什么只有 4,904 条？目标不是 3 万吗？

三个来源的原始岗位是 14,974 条，筛掉非 IT 岗（产品/设计/市场/运营）后剩下 4,904 条。
企业官方招聘站单家只有 1–2 千条技术岗，且美团/阿里/百度/快手等站点都有鉴权（实测返回 401/403），
要扩到 1–2 万需要再接 5–8 家企业。这是"能公开、可持续、合规"与"规模"之间的取舍，已在报告 §9 写明。

## Q4 抽取 F1 只有 0.31，是不是方法不行？

要说清两个数：exact F1 0.306、relaxed F1 0.519。差距来自边界——中文技能 span 的边界本身有歧义
（"沟通能力" vs "的沟通能"）。更重要的原因是训练数据只有 2,141 句：3 个 epoch 后训练 loss 已到 0.03，
是过拟合而不是欠拟合，说明**瓶颈在标注量，不在模型容量**。

## Q5 为什么最终图谱不用模型？

因为模型在域内的边界噪声会污染三元组（抽检里出现"话主框架""工具调"这类碎片）。
我们做了对比：词典路径域内抽检精度 0.925，模型路径明显更低。所以图谱以词典为主，模型作为对照实验保留，
并给出了完整的训练与评测代码——这是有意的工程取舍，不是"模型跑不起来"。

## Q6 为什么不用 LLM 抽取？

课程环境没有稳定的 LLM API 配额；而且 LLM 抽取的问题是**不可复现、成本高、评测难**。
我们的路线（词典 + 微调 BERT）每个环节都能复现和评测。后续可以把 LLM 当作"标注器"来扩标注集，
再蒸馏到小模型，这条路写在报告 §9 的改进里。

## Q7 Schema 为什么不直接用 schema.org？

复用了 9 个（JobPosting / Occupation / Organization / Place / MonetaryAmount 等），
但 schema.org 没有"技能"这个类——只有 `knowsAbout` 属性，无法承载技能的类型、等级、必要性；
也没有"岗位族""薪酬区间（15–25K·14 薪）"这类结构。所以新增 18 个（5 个类 + 13 个属性），每一项在
`schema/schema_extension.md` 里都写了"为什么不够"。

## Q8 图谱质量怎么保证？

三道：① 词典是人工整理的 367 条，命中即高置信；② 后处理裁虚词、限长 2–20 字；
③ 两组评测：随机抽检 40 条，37 条明确成立（精度 0.925）；另做 100 句域内评测，
精确率 0.88、召回率 0.59、F1 0.70。

**关键结论**：一开始召回只有 0.40，漏的是 vLLM、SGLang、Vespa、PagedAttention 这类词表外工具；
补了 39 个工具名词、把「机器学习/大语言模型」等 14 个领域名词从 S 改判为 K、并删掉「开源」这类泛化词之后，
精确率 0.78→0.88、召回 0.40→0.59、F1 0.53→0.70。
说明**扩词表比换模型划算**——而且这个判断是靠评测数据做出来的，不是拍脑袋。

## Q9 和已有的岗位/招聘数据集有什么不同？

OpenKG 上没有同类；公开的中文招聘数据集多是**分类任务**（薪资预测、简历匹配），
我们交付的是**可查询的知识图谱**：schema、JSON-LD、Neo4j 导入文件、检索应用一整套。

## Q10 应用有什么实际价值？

三个场景：求职者按技能组合找岗位；企业/研究者看某岗位族的技能需求分布；个人做技能差距分析
（选目标岗位族 → 缺哪些必备技能，按需求频次排序）。技能差距这一条是从"图谱"而不是"表格"里长出来的。

## Q11 数据合规吗？

只抓公开页面、限速 ≥0.3s、不登录、不碰个人信息；原始 JD 不对外分发，发布的是抽取后的三元组、
聚合统计与每族 ≤20 条脱敏样例；许可证 CC BY 4.0。见 `docs/data_sources.md`。

## Q12 如果再做两周，做什么？

① 再接 5 家企业把规模做到 1.5 万；② 用 LLM 预标注 2,000 句再蒸馏（模型 relaxed F1 0.52 → 0.7）；
③ 补薪资来源（部分国企/事业单位公告有薪资）；④ 把 cnSchema 扩展提成社区 issue。
