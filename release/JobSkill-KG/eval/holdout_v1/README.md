# 独立评测包 v1

已按用户授权由 Codex AI 对 100 句原文进行独立于系统预测的标注与同一代理自查，共 349 个 span。结果不是人工金标准，也不构成两个独立审阅者的一致性验证。该 AI 同时参与了系统实现，存在共同偏差风险。“独立”仅指样本未用于本轮规则调参、标注时未读取该样本的系统预测。

- `ai_span_decisions.json`：逐句明确选定的文本、类别和修饰标签。
- `ai_annotations.jsonl`：精确偏移、AI 身份、复核说明。
- `ai_report.json`：词典与 BERT 在同集上的结果。
- `dictionary_errors.jsonl` / `bert_errors.jsonl`：全部有 span 差异的句子。
- `annotations.jsonl`：原始空白人工模板，未被冒充填写。

运行 `PYTHONPATH=.pkgs:src python3.12 src/extract/score_holdout.py --ai --bert` 重现两种方法的评测。去掉 `--ai` 会要求真正完成的人工模板；AI 状态不能通过人工模式校验。

严格匹配同时要求起止位置与类别相同；宽松匹配要求同类别区间重叠，并使用最大一对一匹配。修饰准确率仅在 exact 命中的 70 个 span 上计算，不能代表端到端关系准确率。标注遵循当前项目 K/S/T/L 约定，未声称与外部 SkillSpan 标注完全一致。

以下是保留的人工复核流程，后续真人复核仍可使用：


本包 100 句来自此前 100 句开发评测未涉及的岗位；每岗位一句，按七个岗位族近似均衡抽样，不按技能提示词筛选。它评估当前语料范围内的表现，不代表整个招聘市场，也不是按真实岗位占比加权的测试。

`annotations.jsonl` 没有预测或预标注。请不要在标注完成之前查看系统抽取输出。冻结输入及样本在 `manifest.json`，不能根据本测试错误修改词典后继续把它当独立测试。

每句由一人标注、一人复核。`spans` 中填入所有技能/知识/通用能力/语言片段：

```json
{"start":3,"end":9,"text":"Python","label":"K","proficiency":"熟悉","necessity":"未说明"}
```

该例对应文本 `熟悉 Python`，位置从 0 开始，end 不包含在片段中；按 Unicode 字符计数。保留原文，不改空白。K=知识、语言或工具名；S=可执行技能动作；T=通用能力；L=自然语言能力。能力片段不包含程度修饰词。不要因词典里没有该技能而漏标；没有技能时保持空列表。

掌握程度取 `了解/熟悉/精通/未说明/冲突`；必要性取 `必备/加分/未说明/不要求/冲突`。未明确说明的不能默认“熟悉/必备”。否定片段仍标注，必要性填“不要求”。根据整句判断修饰范围，不机械套用系统的局部规则。边界和类别争议由两人讨论后记录在可选字段 `review_note`。

完成后填 `status: human_annotated`、`annotator: 实际标注人标识`，复核者填写 `review_status: human_reviewed` 和 `reviewer`。两人标识应不同。标识只需组内可追溯的代号，不需要真实姓名。不将 AI 标注登记为人工。

在项目目录运行：

```bash
python3 src/extract/score_holdout.py
```

未完成、样本被修改或词典/抽取代码变化时，评分会拒绝执行。状态字段是工作流声明，不是系统能独立验证的人类身份证明。

目前只实现当前词典系统评分。BERT 与其他方法的同集对照仍待补充，不能把其他语料上的分数并列当作同集实验。
