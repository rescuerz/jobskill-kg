# JobSkill-KG

中文 IT 岗位技能知识图谱与可追溯查询。浙江大学《知识图谱导论》课程设计，v0.2。

数据为三家互联网企业招聘快照，不代表全行业。4,904 个岗位，390 个技能，12 类技能分类；其中 4,862 个岗位抽到技能。56,496 个节点包含逐岗位的技能要求节点；169,490 条关系边与 450,983 条 RDF 三元组是不同统计口径。

## 运行证据查询

Python 3.12；API 仅使用标准库。先解压公开数据：

```bash
python3 -m zipfile -e JobSkill-KG-data.zip .
python3 src/app/serve_api.py --port 8765
```

打开 `http://127.0.0.1:8765/evidence`。查询“杭州 / 算法 / Python,PyTorch”，命中 54 个岗位；加分技能填 `LLM`，命中 3 个。别名会归一为“大语言模型”。三条演示岗位保留少量原句摘录，其他公开记录仅含来源 URL、字段和位置。原链接可能失效。

`app/site/index.html` 可直接打开浏览画像、检索和技能分类。该静态页的技能缺口表示样本中的技能提及差异，不是求职资格判断。

## 图谱与证据

岗位、企业、城市、岗位族、技能、分类共享稳定标识。岗位通过 `hasRequirement → JobRequirement → forSkill` 表示技能要求；程度与必要性属于岗位要求，不能写在全局技能上。JSON-LD 与 TSV（文件扩展名为 .csv，实际分隔符为 Tab）来自同一图。

缺省标签为“未说明”。局部规则不完整支持跨句作用域、否定和“至少一门”等组合条件，务必结合原句判断。数据集命名空间暂使用规划的 OpenKG IRI；**本轮未发布到 OpenKG，该地址不代表已上线数据集**。

## 评测

100 句冻结样本，349 个参考 span，由 Codex AI 逐句标注并由同一代理自查；没有真人金标准或独立双人复核。AI 同时参与系统实现，可能存在共同偏差。

| 方法 | Exact P | Exact R | Exact F1 | 同标签重叠 F1 |
|---|---:|---:|---:|---:|
| 词典 v0.2 | .660 | .201 | .308 | .378 |
| BERT | .119 | .312 | .172 | .346 |

长尾术语、英文与长动作片段覆盖不足。数据按岗位族均衡抽样，不是总体加权估计。旧开发集 0.703 分数不代表当前独立测试。

原始标注、冻结哈希和逐句错误见 `eval/holdout_v1/`。运行 `python3 src/extract/score_holdout.py --ai` 需要原始完整输入通过哈希检查，因此公开脱敏运行包不能直接复现私有输入的冻结检查；数值可使用公开标签与公开代码离线复算（见评测说明）。BERT 权重及第三方训练语料不再分发，模型哈希和推理配置包含在评测报告中。

## 文件

- `JobSkill-KG-data.zip`：全量图谱、统计、运行所需岗位元数据与脱敏证据。
- `schema/`：本体与 JSON-LD context。
- `src/`：采集、抽取、构图及查询代码；采集与全量重建需要自备来源原文。
- `docs/report.md`：技术报告；`docs/答辩讲稿-v0.2.md`：当前讲稿。
- `SHA256SUMS.json`：公开文件校验值。

代码使用 MIT；派生结构化数据采用 CC BY 4.0，第三方招聘摘录与平台内容的权利归原发布方。无原始全量招聘文本、模型权重、账号凭证。发布状态以 GitHub 实际文件为准；OpenKG 暂不发布。
