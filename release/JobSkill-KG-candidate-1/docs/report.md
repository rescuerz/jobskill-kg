# JobSkill-KG v0.2 技术报告（工作稿）

当前状态：图谱一致性修复和证据查询已实现；独立 AI 标注参考评测已完成；GitHub 发布准备中；按用户要求，本轮不发布 OpenKG。旧版报告保存在 archive/report-v0.1.md。旧版 PDF、PPT 和讲稿尚未同步，不作为 v0.2 结论。

## 范围与数据

面向三家互联网企业公开招聘快照的中文 IT 岗位技能图谱，不推断全行业需求。原始岗位 14,974 条；筛选后 4,904 条，三种公司来源为字节跳动、腾讯、网易。

所有筛选岗位均进入 CSV 和 JSON-LD，包括未抽到技能的岗位；抽到技能的岗位 4,862 个。技能 390 个，分类 12 个。节点 56,496 个，节点间关系边 169,490 条，rdflib 实际解析的 RDF 三元组 450,983 条。节点中包含每个岗位—技能组合的要求节点；规模变化不能解释为新增岗位或额外知识发现。

## 抽取与溯源

当前发布候选采用词典最长优先、不重叠匹配，英文词检查边界。每条技能提及记录原始字段、Unicode 字符偏移、原句、来源链接和采集时间。局部规则识别掌握程度和必要性；缺省为“未说明”，否定要求不进入正向技能关系。多个明确标签冲突时保留“冲突”。同义技能通过别名归一。

局限：修饰范围仅在局部分句内判断；跨行“加分项”标题、跨逗号作用域、否定作用范围、任选技能组合仍可能判断错误。职责中的技能提及不等同于硬性录用要求。词典匹配不输出未经校准的 0.98 置信度。

## 图谱表示

岗位、企业、城市、岗位族、技能和分类均有稳定 IRI；技能跨岗位共享。岗位通过 hasRequirement 连接 JobRequirement，再通过 forSkill 指向技能；proficiency/necessity 属于要求节点。requiresSkill 提供便捷的岗位到技能投影。CSV 的 properties 列保留节点字面属性，JSON-LD 保留同样的关系与属性。

全部边端点存在；自定义对象属性值为 IRI 且 range 类型匹配。样例导出追踪引用闭包，避免样例中悬空引用。

原句保存在本地 job_skills_norm.jsonl，供本地 API 核验。对外候选图谱仅包含来源和偏移等溯源元数据，不含整篇 JD 或证据原句。

## 带证据关联查询

运行 `python3.12 src/app/serve_api.py --port 8765`，访问 http://127.0.0.1:8765/evidence。

API 示例：`/api/evidence?city=杭州&family=算法&skills=Python,PyTorch&optional_skill=LLM`。

本次快照中，杭州＋算法＋Python＋PyTorch 命中 54 个岗位；进一步筛选大语言模型为加分项命中 3 个。HTTP 层已验证后一查询返回 3 个岗位，每个结果包含对应三项技能及原句、位置、来源。结果只证明规则检索行为，不证明所有抽取标签正确。页面已通过浏览器查询验收：组合条件返回 3 项，展示原句、来源链接、字段和字符位置，截图见 figures/evidence_query_v2.jpg。

## 评测

独立集位于 eval/holdout_v1：100 句、每岗位一句、排除旧开发评测涉及岗位、各岗位族近似均衡抽样；不按技能提示词选句。输入和抽取器已冻结哈希。用户已同意由 AI 逐句标注和复核，结果必须称“AI 独立标注评测”，不得称真人金标准。已完成 100 句、349 个 span 的 AI 标注与同一代理自查，未经过真人复核。AI 同时参与系统实现，标注不能视为独立审阅者金标准。

旧版域内 F1=0.703 曾使用同集错误扩词表，不是独立测试；本次抽取代码已变化，更不能沿用该分数。BERT 的旧实验来自另一语料，不能直接作为同集对照。

### 同集结果（AI 标注参考）

| 方法 | Exact P | Exact R | Exact F1 | 同标签重叠 F1 |
|---|---:|---:|---:|---:|
| 词典 v0.2 | 0.660 | 0.201 | 0.308 | 0.378 |
| BERT | 0.119 | 0.312 | 0.172 | 0.346 |

BERT 使用本地冻结 checkpoint、CPU 推理、max_length=128，100 句无截断。两者使用同一批原句和标签，未针对测试错误再调整词典。词典仅在 70 个 exact 命中 span 上，程度与必要性准确率均为 0.900；这是条件准确率，不能称完整关系抽取准确率。

典型错误：LightLLM/Druid/OVS/eBPF 等未覆盖；“Kotlin Multiplatform”只命中“Kotlin”；“多模态大语言模型”被拆成两个词；英语动作与自然语言技能长片段大量漏抽。AI 的边界、类别判断同样可能有争议，详见原始标注与 review_note。
